โปรเจกต์

ทดสอบแอปฯ 'เที่ยวชุมชน' (Manual & Auto)

โปรเจกต์ทดสอบแอปพลิเคชัน 'เที่ยวชุมชน' เพื่อหาข้อผิดพลาดและรับประกันคุณภาพของซอฟต์แวร์

ทดสอบแอปฯ PSRU Bus (Prompt Go)

โปรเจกต์ทดสอบแอปพลิเคชันติดตามตำแหน่งรถรางของมหาวิทยาลัยฯ แบบอัตโนมัติ

กิจกรรม

กิจกรรมอบรมแอปฯ 'เที่ยวชุมชน'

เข้าร่วมกิจกรรมอบรมถ่ายทอดความรู้การใช้งานแอปพลิเคชันท่องเที่ยวชุมชนให้กับผู้ใช้งานในพื้นที่ จ.สุโขทัย

ทัศนศึกษา AUTOMATION EXPO 2025

เข้าร่วมทัศนศึกษาเพื่องาน 'AUTOMATION EXPO 2025' และ 'EEC Automation Park' ที่ ม.บูรพา

ดูภาพเต็ม

ทดสอบแอปพลิเคชัน 'เที่ยวชุมชน'

ดำเนินการทดสอบแอปพลิเคชัน 'เที่ยวชุมชน' ทั้งในรูปแบบ Manual และ Automated Testing เพื่อค้นหาข้อบกพร่อง (Bugs) และตรวจสอบการทำงานของฟีเจอร์ต่างๆ ให้เป็นไปตามที่ออกแบบไว้

เครื่องมือที่ใช้ (Tools Used):

  • Appium
  • Visual Studio Code
  • Google Sheets (สำหรับ Test Cases)
  • Python
  • Android Studio

ทดสอบแอปฯ PSRU Bus (Prompt Go)

ออกแบบและพัฒนาสคริปต์สำหรับทดสอบแอปพลิเคชัน PSRU Bus แบบอัตโนมัติ เพื่อตรวจสอบความถูกต้องของการแสดงตำแหน่งรถไฟฟ้าแบบเรียลไทม์ และทดสอบประสิทธิภาพของระบบ

เครื่องมือที่ใช้ (Tools Used):

  • Appium
  • Visual Studio Code
  • Google Sheets (สำหรับ Test Cases)
  • Python
  • Android Studio

กิจกรรมอบรมแอปฯ 'เที่ยวชุมชน'

ลงพื้นที่จัดกิจกรรม “อบรมถ่ายทอดความรู้การใช้งานแอปพลิเคชันท่องเที่ยวชุมชน” ให้แก่กลุ่มตัวอย่างผู้ใช้งานใน อ.คีรีมาส จ.สุโขทัย

ทักษะที่ได้รับ:

  • การสื่อสารและการนำเสนอ
  • การเก็บรวบรวม Feedback จากผู้ใช้งาน
  • การทำงานร่วมกับชุมชน

ทัศนศึกษา AUTOMATION EXPO 2025

ทัศนศึกษาดูงานด้านเทคโนโลยีระบบอัตโนมัติและหุ่นยนต์ ณ ศูนย์ประชุมนานาชาตินงนุชพัทยา และ EEC Automation Park มหาวิทยาลัยบูรพา

สิ่งที่ได้เรียนรู้:

  • เทคโนโลยี IIoT (Industrial Internet of Things)
  • ระบบแขนกลและหุ่นยนต์ในโรงงานอุตสาหกรรม
  • โซลูชันด้าน Automation สมัยใหม่
