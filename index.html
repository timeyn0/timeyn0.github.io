ทดสอบแอปพลิเคชัน 'เที่ยวชุมชน'

ดำเนินการทดสอบแอปพลิเคชัน 'เที่ยวชุมชน' ทั้งในรูปแบบ Manual และ Automated Testing เพื่อค้นหาข้อบกพร่อง (Bugs) และตรวจสอบการทำงานของฟีเจอร์ต่างๆ ให้เป็นไปตามที่ออกแบบไว้

รายละเอียดการทำงาน

  • ออกแบบและรัน Test Case เพื่อครอบคลุมฟังก์ชันการใช้งานของ User
  • ค้นหาและบันทึกข้อบกพร่อง (Bugs) เพื่อส่งต่อให้ทีมพัฒนาแก้ไข
  • จัดทำสคริปต์ Automated Testing เพื่อลดเวลาการทดสอบซ้ำ

ทดสอบแอปฯ PSRU Bus (Prompt Go)

ออกแบบและพัฒนาสคริปต์สำหรับทดสอบแอปพลิเคชัน PSRU Bus แบบอัตโนมัติ เพื่อตรวจสอบความถูกต้องของการแสดงตำแหน่งรถไฟฟ้าแบบเรียลไทม์ และทดสอบประสิทธิภาพของระบบ

รายละเอียดการทำงาน

  • ทดสอบความแม่นยำของการติดตามและแสดงตำแหน่งรถแบบ Real-time
  • พัฒนาสคริปต์ Automation เพื่อจำลองการใช้งานในสถานการณ์ต่างๆ

ทดสอบเว็บด้วย Playwright (POM)

การพัฒนาสคริปต์ทดสอบซอฟต์แวร์อัตโนมัติ (Automated Testing) ด้วย Playwright Framework สำหรับระบบ Login ของเว็บไซต์ saucedemo.com โดยประยุกต์ใช้โครงสร้างโค้ดแบบ Page Object Model (POM)

รายละเอียดการทำงาน

  • ออกแบบและเขียน Test Script สำหรับทดสอบระบบ Login ทั้งกรณีสำเร็จและล้มเหลว
  • จัดโครงสร้างโค้ดด้วย Page Object Model (POM) เพื่อให้ง่ายต่อการบำรุงรักษาและลดความซ้ำซ้อน

รวมผลงาน Automated Testing (Robot Framework)

คอลเลกชันวิดีโอสาธิตการพัฒนาและรัน Test Script อัตโนมัติด้วย Robot Framework โดยเน้นการประยุกต์ใช้ร่วมกับเครื่องมือจัดการข้อมูลและระบบฐานข้อมูลต่างๆ อย่างครอบคลุม

1. Testing Login Page

สาธิตการเขียนสคริปต์ทดสอบหน้า Login พื้นฐานด้วย Robot Framework ตรวจสอบการทำงานเมื่อกรอกข้อมูลถูกต้องและไม่ถูกต้อง

2. Working With External Database

สาธิตการทำงานร่วมกับ DatabaseLibrary เพื่อทำการเชื่อมต่อ ดึงข้อมูล และจัดการกับฐานข้อมูลภายนอก (External Database)

3. External Database + Login Page

นำข้อมูลที่ Query มาจากฐานข้อมูลภายนอก (External Database) มาประยุกต์ใช้เพื่อตรวจสอบความถูกต้องและเงื่อนไขการ Login

4. RPA.Excel.Files

การประยุกต์ใช้แนวคิดกระบวนการอัตโนมัติ (RPA) จัดการไฟล์เอกสาร Excel เพื่ออ่านและเขียนข้อมูลทดสอบอัตโนมัติ

5. ExcelLibrary + Login Page

ใช้ ExcelLibrary ในการดึงข้อมูล Test Data จำนวนมากจากไฟล์ Excel มาใช้ทดสอบระบบ Login ในหลายๆ รูปแบบ (Data-Driven Testing)

เครื่องมือที่เกี่ยวข้อง (Tools)

Robot Framework Python ExcelLibrary / RPA SQL / DatabaseLibrary
