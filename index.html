คลังวิดีโอ

01Testing Login Page

สาธิตการเขียนสคริปต์ทดสอบหน้า Login พื้นฐานด้วย Robot Framework ตรวจสอบการทำงานเมื่อกรอกข้อมูลถูกต้องและไม่ถูกต้อง

02Working With External Database

สาธิตการทำงานร่วมกับ DatabaseLibrary เพื่อทำการเชื่อมต่อ ดึงข้อมูล และจัดการกับฐานข้อมูลภายนอก (External Database)

03External Database + Login Page

นำข้อมูลที่ Query มาจากฐานข้อมูลภายนอก (External Database) มาประยุกต์ใช้เพื่อตรวจสอบความถูกต้องและเงื่อนไขการ Login

04RPA.Excel.Files

การประยุกต์ใช้แนวคิดกระบวนการอัตโนมัติ (RPA) จัดการไฟล์เอกสาร Excel เพื่ออ่านและเขียนข้อมูลทดสอบอัตโนมัติ

05ExcelLibrary + Login Page

ใช้ ExcelLibrary ในการดึงข้อมูล Test Data จำนวนมากจากไฟล์ Excel มาใช้ทดสอบระบบ Login ในหลายๆ รูปแบบ (Data-Driven Testing)
